WHAT THIS IS
------------
An AI tool that turns a research brief + background documents into a
validated, field-ready market-research survey:

    documents  ->  hypotheses  ->  survey outline (Excel)  ->  questionnaire (Word)

It runs as one web app with three phases and a human approval gate between
each. Phases 1 & 2 use an LLM; Phase 3 (the Word document) is generated by
plain Python, so the same input always produces the same file.

------------------------------------------------------------------------
  IF YOU WANT TO RUN IT  (Windows)
------------------------------------------------------------------------
Requirements: Python 3.11+ and an API key for at least one LLM provider
(Anthropic, OpenAI, Google Gemini, or Groq).

1. Open a terminal in this folder and create the environment:

       python -m venv .venv
       .venv\Scripts\python.exe -m pip install -r requirements.txt

2. Launch the app — double-click  run.bat  (or run it from the terminal).
   A window opens; wait ~20 seconds.

3. Open  http://localhost:8501  in your browser.

4. Paste your API key into the app's sidebar (it stays in memory only,
   it is never saved to disk).

Prefer to run it manually instead of the .bat?

       python -m streamlit run survey_generator/app.py

NOTE: the environment (.venv) is NOT included in this folder — it is large
and machine-specific, so you create it once with step 1 above.


------------------------------------------------------------------------
  IF YOU WANT TO READ THE CODE
------------------------------------------------------------------------
Everything lives in  survey_generator/ :

  app.py            the Streamlit app — all three phases, one file
  contract.py       the shared column contract between Phase 2 and Phase 3
  llm/              multi-provider LLM client + prompt builders
  prompts/          the editable prompt templates that drive each step
  phase1/           research brief + documents  ->  hypotheses
  phase2/           hypotheses  ->  survey outline + the closed-loop validator
  phase3/           survey outline  ->  formatted Word questionnaire (no LLM)
  tests/            pytest suite

Suggested reading order:
  1. survey_generator/README.md      (component overview)
  2. phase2/pipeline.py              (the core: drafting + self-correcting
                                      validation loop)
  3. phase2/validator.py             (the deterministic rule engine)
  4. phase3/word_renderer.py         (deterministic document rendering)

Run the tests from this folder:

       python -m pytest survey_generator/tests -q
